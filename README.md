# Comparatif solutions MDM

## Tableau Comparatif

| Critères | Microsoft Intune | VMware Workspace ONE |
| :--- | :--- | :--- |
| **Écosystème** | Intégration parfaite avec Office 365 / Azure AD | Multi-plateforme (Windows, Mac, iOS, Android) |
| **Sécurité** | Accès basé sur l'identité | Isolation des données robuste : Containerization |
| **Déploiement** | Très simple si l'entreprise utilise déjà Microsoft | Plus complexe, nécessite souvent une expertise dédiée |
| **Coût** | Souvent inclus dans les licences M365 | Licence séparée, généralement plus onéreuse |

## Recommandation
**Solution choisie : Microsoft Intune.**

Pour une entreprise utilisant déjà l'écosystème Microsoft, Intune offre le meilleur rapport coût/intégration. Il permet de bloquer l'accès aux emails pro si le téléphone n'est pas chiffré ou si une application malveillante est détectée, répondant ainsi directement aux risques identifiés lors de notre audit.
